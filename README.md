## 主要项目 / Selected Work

### Amia / Mizuki 与音游

- **[MizukiBot](https://github.com/Amia-Mizuki-Dev-Team/MizukiBot)**：Amia_晓山瑞希 Bot 的公开项目入口、文档、功能说明与更新信息。
- **[Amia-plugin-maimaidx](https://github.com/Amia-Mizuki-Dev-Team/Amia-plugin-maimaidx)**：舞萌 DX 综合插件，整合 LXNS / DivingFish 双数据源、玩家查分、曲库查询、B50、进度统计、群聊互动、OAuth 与 `MaimaiDataProvider`。
- **[Amia-plugin-pjskhelp](https://github.com/Amia-Mizuki-Dev-Team/Amia-plugin-pjskhelp)**：PJSK 查询与本地竞猜方向插件，持续补全资源、Media Service 与竞猜链路。
- **[Amia-Sync-Android](https://github.com/HX-Wrdzgzs/Amia-Sync-Android)**：舞萌 DX Android 第三方客户端的公开版本；当前部分新架构与服务端组件在私有仓库维护。
- **[hx-pjsk-gateway](https://github.com/HX-Wrdzgzs/hx-pjsk-gateway)**：连接 PJSK Web 查询、机器人验证与数据节点的网关。

### Web、系统与基础设施

- **[homepages](https://github.com/HX-Wrdzgzs/homepages)**：个人主页，采用蓝黑视觉体系，包含独立项目页、搜索、筛选、分页、快速预览与多页面导航。
- **[HongXingWeb](https://github.com/HX-Wrdzgzs/HongXingWeb)**：Hong Xing 技术 / 项目 / 服务官网，包含项目、基础设施迁移、公告、生命周期、支持下载及 Amia 生态页面。
- **[GensokyoNewQQWeb](https://github.com/HX-Wrdzgzs/GensokyoNewQQWeb)**：Gensokyo-NewQQ 配套文档站，持续跟进 OneBot、WebUI 与相关兼容变化。
- **[retro-monitor](https://github.com/HX-Wrdzgzs/retro-monitor)**：基于 Windows、Home Assistant 与 ESP32-S3 的本地硬件监控系统。
- **[ag-pocket-console](https://github.com/HX-Wrdzgzs/ag-pocket-console)**：基于 `PreToolUse` Hook 的移动审批与监督控制台实验。

### Amateur Radio / BA4THG

- **[ham-checkin-assistant](https://github.com/HX-Wrdzgzs/ham-checkin-assistant)**：业余无线电中继点名与记录辅助工具。
- **[BA4THG-QSL](https://github.com/HX-Wrdzgzs/BA4THG-QSL)**：BA4THG 的 QSL 展示与查询页面。
- **[BA4THG-QSO](https://github.com/HX-Wrdzgzs/BA4THG-QSO)**：QSO 记录与相关 Web/API 工具。
- **[uv-k5-repeater-web](https://github.com/HX-Wrdzgzs/uv-k5-repeater-web)**：面向 UV-K5 / 中继场景的 Web 工具实验。

## 当前关注 / Current Focus

- Amia / Mizuki 插件生态的 Provider、身份、权限、发送链路、错误码与审计契约

- PJSK 本地资源同步、Catalog / Media Service、竞猜引擎与 Release012 兼容
- Hong Xing 项目站、HongXingOS 7 相关页面、基础设施迁移与 Cloudflare Pages 部署
- Home Assistant、ESP32-S3、GitHub Actions 与保留人工确认的自动化工具
- BA4THG QSO / QSL、点名辅助及业余无线电 Web 工具
